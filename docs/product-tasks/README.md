# Product task specifications (frozen)

> Historical record. Kept as recorded; not the current contract.

Every file in this folder is the specification of one past product task, written at the time of that task. They are
point-in-time instructions and may name fields, routes or components as they were then (including legacy Portuguese
names that have since been renamed). They are not the current contract and nothing reads them: the current contract is
`docs/NAMING_NORMALIZATION_CANONICAL_MAP.md` (generated from `docs/naming/canonical-naming-map.json`) and
`docs/engineering/pack/CANONICAL_TECHNICAL_VOCABULARY.md`. The naming census does not scan this folder's code spans for
that reason (`isCurrentDocForCode` in `scripts/naming/technical-naming-census.mjs`).
